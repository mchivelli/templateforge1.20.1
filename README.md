# The Warborn Origins

An Origins addon for Minecraft Forge 1.20.1 that adds 14 playable races, each with unique powers, strengths, and weaknesses. Built as an addon for the [Origins](https://www.curseforge.com/minecraft/mc-mods/origins-forge) mod by Apace100 and EdwinMindcraft.

## Origins

### Wood Elf
Nature-attuned forest dwellers. Race attribute: **Vegetarian**.

| Power | Effect |
|-------|--------|
| Elven Stature | 1.2x height via Pehkui (persists through respawn) |
| Nature's Veil | Invisibility + night vision while in vegetation, lingers 1.5s |
| Flammable | +50% fire/lava damage taken |
| Light on Feet | -50% fall damage |
| Flower Affinity | Carry 3+ flowers for passive effects (Speed, Strength, Water Breathing, Fire Resistance, Luck, Jump Boost, Regeneration) |
| Skinny | Slender elven physique |

### Moon Elf

| Power | Effect |
|-------|--------|
| Lunar Stature | 1.15x height, 0.9x width via Pehkui |

| Moonlit Veil | Invisible while sneaking at night (stealth meter resource) |
| Night Strike | 2x damage from stealth at night, breaks invisibility |
| Assassin's Focus | -30% damage when stealth meter is not full |
| Hydrophobia | Damage in water/rain (Aqua Affinity helmet negates) |
| Fragile | -6 max health, +15% physical damage taken |
| Ethereal | Faint blue lunar glow |

## Race Attributes

- **Vegetarian** (Wood Elf, Moon Elf, High Elf) - Eating meat causes Nausea, Poison, and Hunger.
- **Carnivore** (Goblin, Arachnae, Orc) - Eating plant-based food causes Nausea, Weakness, and Hunger.
- **Mine Faster** (Dark Dwarf, Mountain Dwarf, Wild Dwarf) - +30% mining speed.
- **Night Vision** (Siren, Piglin Kind) - Permanent Night Vision.
- **None** (Human, Plague Victim, Revenant) - No shared race attribute.

## Installation

1. Install Minecraft Forge 1.20.1.
2. Download and install all required mods listed above.
3. Download The Warborn Origins JAR from the releases page.
4. Place the JAR in your `mods` folder.
5. Launch the game and select your origin.

## Configuration

Configuration file: `config/warbornorigins-common.toml`

| Option | Default | Description |
|--------|---------|-------------|
| Elven Height Scale | 1.2 | Height multiplier for Wood Elves |
| Night Vision Duration | 40 ticks | How long night vision lingers after leaving vegetation |
| Night Vision Cooldown | 60 ticks | Cooldown before night vision reapplication |
| Max Flower Effects | 2 | Maximum simultaneous flower effects |
| Flower Stack Required | 3 | Number of flowers needed to activate an effect |

### Customisation
Server admins can modify powers by editing JSON files under:
```
data/warbornorigins/powers/
```

Item tags (meat, vegetarian food, heavy armor, gold gear, magic damage) can be extended via:
```
data/warbornorigins/tags/
```

## Compatibility

The Warborn Origins is designed to work alongside other Origins addons and popular mods:

- **Iron's Spells and Spellbooks** - Magic damage types are tagged for High Elf and Moon Elf interactions.
- **Pehkui** - Used for stature scaling on 11 origins. Human, Plague Victim, and Revenant use vanilla player scale.
- **Other Origins addons** - Uses the non-replacing origin layer so it stacks with other addons.
